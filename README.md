## New Explorer – Frontend Project

New Explorer es un proyecto frontend desarrollado con React + Vite, enfocado en la búsqueda y visualización de información, priorizando una estructura clara, manejo de estados y una correcta gestión de errores.

### Tecnologías utilizadas

    * React
    * Vite
    * JavaScript (JSX)
    * CSS (Flexbox y Grid)
    * pnpm

### Funcionalidades principales

- Búsqueda dinámica mediante palabras clave
- Manejo de estados y funciones para el control de datos
- Gestión de errores:
- Error de servidor (usando la palabra clave error)
- Resultado no encontrado (usando la palabra clave none)
- Renderizado condicional según el estado de la aplicación
- Uso de imágenes en formato SVG
- Tarjeta de noticias guardadas _SavedNews_

### Diseño responsive

El proyecto está adaptado a las siguientes resoluciones:

- 320px
- 768px
- 1440px

Las transiciones entre resoluciones podrán optimizarse en entregas posteriores.
Posteriormente se añadira la opcion de Login para que cada usuario pueda almacenar
sus noticias destacadas.

#### Para ejecutar el proyecto, clonar el repositorio local

- pnpm install
- pnpm dev
